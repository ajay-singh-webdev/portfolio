05b / Audit Lab

Free SEO Tools

Quick, browser-based checks for common on-page and technical SEO tasks. No data is sent to a server.

01On-page

Meta Tag Checker

Check title, meta description, canonical URL, robots meta and social tags from pasted HTML.

02Content

Word Counter

Count words, characters, sentences and paragraphs while checking reading length.

03Keywords

Keyword Density Checker

Find the most-used terms and calculate approximate keyword density from your content.

04Structure

Heading Checker

Review H1, H2 and H3 structure and spot missing or excessive primary headings.

05Technical

Robots.txt Tester

Paste robots.txt rules and test whether a path is allowed or blocked by common rules.

06Technical

Sitemap Checker

Paste XML sitemap content to validate common sitemap structure and URL entries.

Note: These tools run locally in your browser. A static GitHub Pages portfolio cannot reliably fetch arbitrary websites because of browser CORS restrictions, so the URL-based checks use pasted HTML, robots.txt or sitemap content.
